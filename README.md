## Assignment 2: Excel model

`ShopEase_Schedule_Budget_Model.xlsx` contains the activity list with three-point estimates, the dependencies (FS/SS/FF with leads and lags), the forward and backward pass, floats and critical path, the bottom-up budget, the time-phased S-curve, crashing options, and progress with earned value. All values are formulas, so changing a duration, dependency, rate or the status date recalculates the schedule, budget and charts.

## Assignment 3: Kanban board

`ShopEase_Kanban_Board.html` runs in any browser. Cards can be dragged between Backlog, Ready, In progress, Review / Test and Done (WIP limits 6 / 5 / 3). Every move is dated with the status date and recalculates cycle time, lead time, throughput, velocity, the cumulative flow diagram, PV / EV / AC, SPI, CPI and EAC. The RACI matrix tab checks that every activity has exactly one A and at least one R. Status date: 3 Oct 2026.

## Assignment 4: Risk register

`ShopEase_Risk_Register.html` holds 15 threats and 5 opportunities with owners, probability, cost and schedule impact, P x I score, EMV and response. Risks are plotted on probability-impact matrices for threats and opportunities (drag to re-rate, before / after response). The quantitative tab compares the net EMV with the contingency reserve and runs a Monte Carlo simulation of the go-live date and cost over the project network. Status date: 10 Oct 2026.

Both web pages save changes in the browser; use "Reset to baseline data" to return to the submitted state.
